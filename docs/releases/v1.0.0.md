# WorldModel Studio 1.0.0

多语言桌面 AI 研究与影像创作工作台。

## 下载

- macOS Apple Silicon / Intel，DMG 安装包，Developer ID 签名与 Apple 公证
- Windows x64，EXE 安装向导，当前未进行 Authenticode 签名
- Linux x64，DEB 和 RPM

macOS 打开 DMG 后将应用拖入 Applications。Windows 运行安装向导。Linux 选择适合发行版的 DEB 或 RPM 包。

## 功能

- 内置创作理论与个人 PDF / 文本的分页 RAG 检索、引用和流式 Markdown 对话
- 中文、English、日本語，AI 新回复跟随界面语言
- ZenMux 模型管理、思考强度、自动与手动代理设置
- 图像与视频生成，参考图、比例和视频时长控制
- 可直接填入发送区的提示词，文字复制、媒体下载和复制
- 图像平移缩放，会话置顶、批量导出与删除联动

使用前在设置中填写个人 ZenMux API Key。模型调用由 ZenMux 计费，模型与参数的可用性以平台为准。API Key 使用操作系统加密能力保存。
